Choose a cookbook for a task like reviewing documents, guarding agent commands, or matching product records. Each shows the question, the spec, the measured result, and when that approach falls short. The example specs are in [`prototype/examples/`](https://github.com/oneryalcin/hunch/tree/main/prototype/examples).

Several cases use AI review panels, source labels or the author's own reviews. Those are different forms of evidence, and none alone establishes how a spec will work on your data. Each case's measurement notes say which it used.
